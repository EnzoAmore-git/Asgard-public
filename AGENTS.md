Рабочая папка F:\Проекты\Asgard-public. Только презентационный сайт; приложение развивается отдельно.

- Перед изменениями читать текущий запрос и этот файл. Тексты, роли, путь и крупные направления развития находятся в content.js; структура — index.html, оформление — style.css, поведение — script.js.

- При подтвержденном завершении крупного направления обновить content.js: статус, описание, следующий шаг и дату. Не переносить сюда перечень задач/коммитов, не вычислять выдуманный процент готовности. Простая смена даты не означает развитие.
- Обновление статуса — проверяемое изменение файла с последующей публикацией через GitHub Pages; автоматического чтения приватного репозитория или API приложения нет.
- Сначала проверять реальное состояние проекта; будущие возможности не называть работающими. Не придумывать цены, сроки, клиентов, отзывы или новые функции.
- Не добавлять базу, реальные паспорта, персональные данные, секреты или служебные документы. Публичные картинки и шрифты — assets/; лицензии сохранять.
