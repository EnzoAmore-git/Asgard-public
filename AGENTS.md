# Публичный лендинг Асгарда

Рабочая папка F:\Проекты\Asgard-public. Только презентационный сайт; приложение развивается отдельно.

- Перед изменениями читать текущий запрос и этот файл. Тексты, роли, путь и крупные направления развития находятся в content.js; структура — index.html, оформление — style.css, поведение — script.js.
- Сохранять Mobile First и северный стиль: глубокий бордовый вместо зелёного, медь и тёплые светлые разделы. Проверять 320/390/768/1440 px, отсутствие горизонтальной прокрутки, клавиатуру, видимый фокус, reduced-motion.
- Показывать всю экосистему: клуб, реконструктор, паспортист, организатор, гость. Паспорт не означает автоматический допуск. Решение принимает фестиваль.
- При подтвержденном завершении крупного направления обновить content.js: статус, описание, следующий шаг и дату. Не переносить сюда перечень задач/коммитов, не вычислять выдуманный процент готовности. Простая смена даты не означает развитие.
- Обновление статуса — проверяемое изменение файла с последующей публикацией на https://asgardapp.ru (Beget); автоматического чтения приватного репозитория или API приложения нет.
- Сначала проверять реальное состояние проекта; будущие возможности не называть работающими. Не придумывать цены, сроки, клиентов, отзывы или новые функции.
- Не добавлять базу, реальные паспорта, персональные данные участников, секреты или служебные документы. Публичные картинки и шрифты — assets/; лицензии сохранять.
- Контакты автора: https://t.me/enzoamore, https://vk.ru/enz0amore и info@asgardapp.ru. Технические письма об аккаунте отправляет отдельный ящик account@asgardapp.ru. Ничего не отправлять от имени посетителя.
- Основной адрес — https://asgardapp.ru. GitHub Pages служит переходом со старого адреса, push сам по себе не обновляет Beget. Публиковать только index.html, style.css, script.js, content.js, favicon.svg, robots.txt, sitemap.xml, .htaccess и assets/. Не копировать весь репозиторий, инструкции и файлы разработки. README оставить коротким.
- Продакшен приложения app.asgardapp.ru будет размещаться отдельно от файлов лендинга в рамках существующего сайта Beget. Текущая .htaccess обслуживает только основной домен и www; перед подключением приложения нужна отдельная маршрутизация. Не направлять app в учебную БД.

Блок автора в index.html: только предоставленные Денисом факты и разрешённое им фото assets/denis-ded-*.webp. Не дописывать биографию от себя; факт готовности приложения от изменения этого блока не меняется.
