# Асгард

Экосистема для исторической реконструкции: клубы, участники и фестивали. Проект объединяет работу клуба, паспорт реконструктора и взаимодействие с организаторами.

В работе над проектом я уточнял потребности участников, описывал пользовательские сценарии и последовательно развивал продукт. Отдельное внимание уделял понятным ролям, удобству на телефоне и визуальному образу, связанному с темой реконструкции.
