# Асгард

Презентационный сайт экосистемы исторической реконструкции: клуб, паспорт реконструктора, заявки и проверка, программа и карта фестиваля.

[Открыть сайт](https://asgardapp.ru/)

Статическая страница без регистрации и сбора данных. Тексты, роли и крупные этапы развития — в `content.js`. Основной сайт размещён на Beget. GitHub Pages перенаправляет на основной домен; обновление Beget выполняется отдельно. Инструкция сопровождения — `AGENTS.md`.
